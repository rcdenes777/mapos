# MapOS — instruções para agentes

O estado do projeto, como subir o ambiente, os gates de verificação, as
armadilhas já conhecidas e as pendências abertas estão em **`AGENTS.md`**,
nesta mesma pasta. **Leia esse arquivo antes de agir.**

Este arquivo existe apenas para que agentes que procuram `CLAUDE.md` cheguem ao
mesmo conteúdo. Mantenha o texto em `AGENTS.md` e deixe este aqui curto — não
duplique, para não criar duas versões que divergem com o tempo.

## Autoridade

Git, código, testes e decisão humana atual **vencem** qualquer narrativa de
memória ou handoff. Memória é consulta e pista, nunca fonte de verdade.
